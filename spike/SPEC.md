# 界面规范（引擎对比用）

这份文件只做一件事：把 `docs/DESIGN_SYSTEM.md` 与三份参考纪律里**影响观感**的部分压成一页，
让同一个页面在两个候选引擎上长得一样、也只差引擎本身。

来源：`docs/DESIGN_SYSTEM.md`、`leonxlnx/taste-skill`、`pbakaus/impeccable`、`emilkowalski/skills`。

## 1. 材质

四档厚度，从薄到厚：`bar 0.78 · button 0.88 · card 0.95 · dialog 1.15`（相对倍率）。
一块玻璃由六层叠成，顺序不可调换：

1. **糊底**：背后真实内容的模糊取样（`backdrop-filter: blur(18px) saturate(140%)`）。
   纯色背景时这一层什么也透不出 —— 这正是「看不出是玻璃」的根因，所以页面底必须是一层有明暗的渐变。
2. **边缘折射**：边缘 2~8px 的一圈里内容被挤压（模拟透镜）。
3. **侧壁**：贴边 2~4px 的一圈，迎光侧内壁亮、背光侧内壁暗。
4. **柱面**：上下两条 5~10px 的带，把糊底竖向压到 0.6 倍。
5. **面**：左上亮 → 中段 → 底沿暗，明暗差 0.26 → 0.045。
6. **材料柔光**：左上偏内一枚无边界径向光（不是棱上那条高光）。

规则：

- 大的面读起来更厚（按面积开方缩放 0.75~1.6 倍）。
- **不要在另一层半透明面上再叠一层浅色半透明**：容器实一点，只有浮层与按钮透。
- 纯色背景下玻璃等于塑料 —— 要么给地面一层渐变，要么这块就用实心。

## 2. 墨阶与自动反色

墨阶不是选颜色，是**算**出来的：

- 合成面 = 糊底平均色 → 卡面 tint（浅档 6~10%、深档 8~12%）→ 面上受光 7%。
- 面亮则墨深、面暗则墨浅；目标比按地面能拿到的**天花板等比缩放**，拿不到时先保层次。
- 判据：正文 ≥ 4.5:1、大字号 ≥ 3:1。
- 文本框里的字与占位文字同属正文，不是例外。

## 3. 色

- 地面无彩（chroma 接近 0），世界的性格交给强调色与材质。
- 强调色只出现在：主行动、当前选中、状态指示。不做装饰。
- 深浅两档由同一套种子推导，不手抄两份颜色表。

## 4. 动效

- 反馈 100~150ms；例行状态 150~300ms；过场 300~500ms；编排式入场 500~800ms。
- 退出比进入快。进门用 ease-out，出门用 ease-in。
- 可动控件用弹簧：默认阻尼 1.0（不过冲）；只有带惯性的手势（甩、拖放）才给 0.8 的回弹。
- **一个时钟**：一次交互里所有会动的东西由同一条时间线推进，中途再输入从**当前值**接手（不回到起点）。
- 动的是 transform 与 opacity；宽度、高度、位置不参与动画。

## 5. 指针即光源

- 光在窗口里只有一个位置；每块玻璃自己算方向与衰减。
- 衰减：`(1 - d/R)^1.35`，`R ≈ 520dp`；块外时投影贴到最近的边。
- 光**不进材质缓存**：材质只在几何/配色/按下状态变化时烘一次，光每帧现画。

## 6. 控件与平台

- 平台控件只借输入语义，不借外观：输入框、下拉框的系统边框/圆角/焦点矩形一律去掉。
- 开关、滑杆、按钮全部自绘，与玻璃同一套材质。
- 浮层（下拉、菜单、提示）的底色与字色跟随令牌，不读系统主题。

## 7. 本次对比页面的范围

一屏设置页，包含：

- 顶栏：返回、页名（只文字，无图标）、一条发丝线。
- 卡片：标题「玻璃效果」+ 四行（轻量模式开关 / 玻璃透明度滑杆 / 磨砂程度滑杆 / 液态高度滑杆）+ 一行说明。
- 卡片外一颗主按钮（Signal 档，强调色）。
- 指针在窗口任意位置移动时，卡片与按钮上的光跟着走，越远越暗。

两边的布局、间距、字号、颜色、圆角必须一致；允许不同的只有引擎本身的渲染与动画实现方式。
