# 入口与版式规范（DESIGN-ENTRY）

这份文件管四张面：标题页、主界面顶栏与菜单、手机桌面、设置首页的分组卡。
它只管「入口怎么排、读数怎么显示」，不管业务内容。字号、间距、栅格三条底层合同见
`src/styles/kit.css` 文件头；这里只补入口这一层。

## 一、入口单元（Entry）

一个入口恒为五层，从上到下、从左到右固定：

| 层 | 位置 | 档位 | 颜色 | 规则 |
| --- | --- | --- | --- | --- |
| 图形标记 | 最左，或方格内 | 16 / 20 / 32（按规模） | `--w-ink-label` | inline SVG 自绘，1.5px 描边，只用 `currentColor`；没有字形可用时用字标（短名或首字） |
| 编号 | 标记右侧 / 方格上方 | `--w-size-caption` | `--w-ramp-5` | 两位补零（01…NN），等宽数字，右对齐在 `2.4ch` 一列 |
| 名称 | 编号右侧 | 主入口 `--w-size-subhead` 600；次级 / 工具 `--w-size-body` 600 | `--w-ramp-1` | 单行，超长省略号 |
| 一行说明 | 名称下方 | `--w-size-caption` | `--w-ramp-4` | 单行，省略号；没有现成文案就不写这一层，不补字 |
| 状态位 | 最右，或标记角上 | `--w-size-caption` | `--w-status` / `--w-signal` | 只有一个：未读数、禁用、当前。没有就不占位 |

几何：

- 编号列固定 `2.4ch`，编号与名称间距 `--w-step-2`，编号右对齐；`01、02` 因此上下对成一条竖线。
- 一个入口内部只用两档间距：层与层 `--w-step-1`，列与列 `--w-step-2` 或 `--w-step-3`。
- 整块入口的左边界压在同一根栅格线上（页内 `--w-rail` 加 `--w-pad-page`；卡片内加卡片内距）。换行、换栏都不破例。

反馈（只动 `transform` / `opacity`）：

- 悬停：先落左侧 3px 位置色条（`--w-signal`），`transform: scaleY()` 从顶端展开，120ms `--w-ease-out`；
  再让「编号 / 名称 / 说明 / 状态」这一组整体右移 `4px`，160ms `--w-ease-out`。文字颜色不变。
- 按压：整块下压 `1px`（`transform: translateY(1px)`），120ms；不改背景、不改字号。
- 当前项：左侧色条常驻；同时名称加粗（颜色之外再给一个可辨信号）。
- 禁用：`opacity: 0.45`，悬停无反应，`cursor: default`。
- `prefers-reduced-motion: reduce` 时全部时长归零，色条仍出现（它表达状态，不是动效）。

## 二、三种规模

| 规模 | 行高 / 尺寸 | 图形标记 | 编号 | 说明 | 用在哪 |
| --- | --- | --- | --- | --- | --- |
| 主入口 | 64（内距 12 / 16） | 20–24 | 有 | 有（有文案才写） | 标题页四个入口 |
| 次级入口 | 52（内距 12 / 16） | 无，编号顶位 | 有 | 有 | 设置分组卡的每一行 |
| 工具入口·条 | 32 高（内距 0 / 12）；弹层里 48 | 无 | 可选 | 无 | 主界面顶栏、菜单行 |
| 工具入口·格 | 方格 44–58 | 方格本身即标记 | 无（由所在分区的编号承担） | 有 | 手机桌面与 Dock |

工具入口的「条」与「格」是同一档的两种排法：一样小、一样只用 caption 与 small 两档字、一样不做说明。
顶栏一行 32 高（鼠标为主），弹层菜单一行 48 高（手指为主）；两处编号列仍是 `2.4ch`，不因高度变了就变宽。

## 三、布局栅格

- 列宽只有一根：`--w-rail`（1080）加两侧 `--w-pad-page`。页头、标题、卡片、列表第一列全部压在它上面。
- 断点四档，全部用 4 的倍数控制块间距离：

| 视口 | 设置组卡 | 标题页 | 主界面 |
| --- | --- | --- | --- |
| ≥ 1281 | 双栏，中间 1px 竖发丝线 | 左导航带 262 + 1px 线 + 右主区 | 左栏 180 + 舞台（+ 聊天 300） |
| 1025–1280 | 同上 | 同上 | 同上 |
| 901–1024 | 同上 | 同上 | 顶栏读数横滚，左栏保留 |
| ≤ 820 / ≤ 900 | 单栏 | 上下叠成一列，撤掉竖线 | 左栏与聊天栏收起 |

- 区块切开只用「编号 + 名称 + 一条到右缘的发丝线」：`.group` / `.k-group` / `.pn__sect` 共用同一份几何
  （`2.4ch` 编号列、`--w-step-2` 间距、`1px` 线用 `--w-ramp-6`）。不再用带边框的卡片去切块。
- 卡片的左边界必须落在栅格线上；卡片内部再切行，行与行之间只画 `--w-hairline`，不画卡片描边。

## 四、显示规范

读数三层（标签 → 数值 → 单位）：

- 标签在上：`--w-size-caption`，`--w-ramp-5`，不换行。
- 数值在中：`--w-size-subhead` 700，`--w-ink-display`，`font-variant-numeric: tabular-nums`（多位数不抖）。
- 单位小一号：`--w-size-caption`，450，`--w-ink-muted`，紧贴数值，间隔 `--w-step-1`。
- 读数带里每一项左侧一根 `--w-hairline`，间距 `--w-step-3`；第一项不画线。

列表行（次级入口）：

- 一行 52 高，编号 / 名称 / 说明 / `›` 四格；`›` 常驻，用 caption 档 `--w-ramp-5`，它不是装饰，是「这一行会带你走」。
- 行与行之间 `box-shadow: inset 0 1px 0 var(--w-hairline)`，首行不画；悬停时左侧色条落下（同入口单元）。

状态位：

- 只用现有的 `--w-status` 一族（`--w-status` / `--w-status-fg` / `--w-status-edge` / `--w-status-tint` / `--w-status-ink`），
  不新造色相。当前项与警示用 `--w-signal`；禁用用 `opacity`。
- 状态位永远带文字或形状，不单靠颜色：未读数写数字，禁用降透明度，当前项加粗。

## 五、不要做的事

- 不用黄黑警示条、斜线危险带、雷达扫描这类「工业贴纸」；我们的工业感来自细线与编号，不来自条纹。
- 不用任何品牌字标、游戏官方字体、外部图标库。图形只有自己画的 inline SVG，或者字标。
- 不写十六进制色值与行内颜色函数；颜色只写令牌名。
- 不做圆角按钮配投影。块状可点件（按钮、方格入口）切右上 6–8px 角；整行入口不加切角，用左侧位置色条说明可点；展示内容一律直角。
- 不在同屏混用两种规模：一个面只用主入口，或者只用次级入口，或者只用工具入口。
- 不做循环装饰动画、不做弹跳与缩放弹出；不做大于 4px 的位移。
- 不给编号凑数：`01、02` 就是顺序，不伪造编号、日期、坐标。
- 不为了「密度」删掉说明或状态：宁可加高一行，也不把两层压成一层。
