WarmAsBefore × Touhou Little Maid

Minecraft 女仆桥 让存档里的角色，在 Minecraft 世界里有一具真的会行动的身体

温暖如初是大脑——人格、好感、信任、记忆、日程都在这里； 游戏模组是身体——坐标、背包、饥饿、挖掘、取水、投喂发生在方块世界里。 数值面板只显示，权威值在 WAB 存档；游戏里的每一次互动都会回到 WAB 的记忆层。

一、两台机器怎么对话

WarmAsBefore（大脑）
桥服务UDP 发现 + TCP 会话，收状态发指令
maid_* 工具 ×9聊天里 AI 直接调用
存档与记忆层好感/信任/记忆/NBT 快照
⇄UDP 27321beacon / offer
⇄TCP 27322NDJSON 帧
Minecraft Forge 1.20.1（身体）
WabBridge生命周期 / 会话 / 心跳

WabAutonomy日程与随机自发行为

配对的五个步骤

  1. 选端口：插件设置 port（默认 27322，0 = 自动挑空闲口）。宿主启动时读取。
  2. 游戏里广播：模组每 3 秒向 UDP 27321 发 beacon（回环 + 广播地址都发，覆盖同机与局域网），带世界名、玩家名、女仆清单。
  3. 宿主应答：收到 beacon 后向来源单播 offer：TCP 端口 + 一次性 token + 30 秒证明（HMAC-SHA256）。
  4. 校验握手：模组连上 TCP 先发 hello（nonce + token）。宿主核对 token 与证明后回 welcome，绑定存档与角色。
  5. 开始协作：之后是常态循环——模组上报 state 快照与 event 事件；宿主下发 command（九种指令）与 stats；每 10 秒一次 ping/pong 心跳，30 秒没心跳就断开重来。
安全边界：token 30 秒过期且只用一次；默认只听回环地址，局域网要显式打开； 模组只执行白名单动作；JS 插件本身没有网络能力，出网的只有宿主桥服务这一条路。

二、AI 能对她做的九件事

工具作用举例
maid_status她此刻的真实状况：维度、时间、天气、生命、饥饿、坐标、背包、附近玩家、爱恋数值“你现在怎么样？”
maid_scan环顾四周：附近生物、矿石、容器、作物、水/岩浆、亮度挖矿前先看看
maid_go真的走过去：to / near / follow / wait / home / wander，寻路不瞬移“来我这儿”
maid_gather动手采集：mine / collect / chop / harvest / scoop / fill，返回实际拿到的东西挖 16 个矿石
maid_hold物品与投喂：give / drop / take / feed_player / place / equip直接把食物喂给玩家
maid_act动作：attack / use / gesture / say / sit / stand / sleep / look / interact_addon主动抱抱
maid_plan一天的日程：几点去哪做什么、执行概率、空闲时的自发行为；由模组本地执行“晚上 9 点来喊我”
maid_bind把她绑定到某个角色；女仆太多时可以新建角色甚至新建存档每个女仆一个角色
maid_backup把她完整的 NBT（背包/状态/AI/日程）快照进 WAB 存档，保留最近 40 份大动作前留底

原则：不瞬移 移动靠寻路，太远会先 go； 不凭空造物 矿是真的挖出来的，进她背包； 不隔空取物 投喂要站在 3 格内； 可中断 每个长动作都有 tick 预算，超时返回已完成的部分； 一次只做一件 新指令会取消旧动作并如实说明。

三、谁说了算（数据归属）

数据权威方说明
好感 / 信任 / 心情 / 精力WarmAsBefore游戏端只显示；模组只能“请求加分”，宿主决定接不接受
生命 / 饥饿 / 坐标 / 背包Minecraft 模组WAB 只读 + 定期快照备份，不回写
爱憎分明的信任/恐惧/饱食爱恋模组读取展示；动作通过反射调用，装了才生效，不装只记日志
记忆 / 关系网 / 日程计划WarmAsBefore游戏事件回传后写入记忆层，聊天加好感（每句 +1，每 5 句 +1 信任）

四、设置键（宿主按这些键工作）

键默认说明
enabledtrue总开关。关掉后宿主不监听端口，游戏回落到原版行为
port27322TCP 端口，0 = 自动；改动会热更新，不断已有会话
lanfalse允许局域网连接，默认只听回环
auto_create_characterstrue匹配不到角色时按女仆名新建
allow_world_actionstrue挖/放/取水/丢物这类改世界的动作
allow_gesturestrue动作与语录这类不改世界的动作
chat_affectiontrue游戏内聊天回传并加好感
autonomy_pulse_minutes0WAB 主动思考间隔；0 = 完全交给游戏里日程
backup_minutes10NBT 快照间隔；0 = 只在连接与手动时备份

五、安装与联调

  1. 游戏端：把编译好的 touhoulittlemaid-*.jar（含 WAB 桥）放进 Forge 1.20.1 的 mods 目录；同一台机器上开世界，模组会在服务端每 3 秒广播 beacon。
  2. WAB 端：插件中心安装本插件（plugin.json 所在的目录或 zip），确认上面「设置」里 enabled 为开。
  3. 两边都在跑之后无需手动操作：握手自动完成。游戏内女仆头顶会出现行动栏提示（好感/信任），聊天里问“她在哪”时 AI 会自己调 maid_status 回答。
连不上先查：① 同一个 world + 同一个玩家；② 防火墙放 UDP 27321 与 TCP 端口； ③ 日志——WAB 在 logs/app.log（前缀 MaidBridge），游戏在 logs/latest.log（前缀 [WAB]）。 模组崩溃或 WAB 没开都不影响游戏本身运行。
