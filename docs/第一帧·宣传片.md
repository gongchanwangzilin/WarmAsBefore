## 文案口径

- 片名与长片一致：**第一帧**。它指的不是"第一个版本"，是"一个会衰减的东西，第一次被允许活下去"。
- 全片不用感叹号、不用"革命性/颠覆/重新定义"，不做产品功能罗列——功能在 README 里，宣传片只负责说一句话。
- 唯一的数字承诺是三个半衰期（0.25h / 6h / 72h），因为它们是代码里的常量，可验证。

## 复现

渲染器是纯程序化出帧（PIL）+ 合成音床（numpy），原始帧直接灌进 ffmpeg，不落中间图：

```powershell
python docs/promo/render_promo.py docs/promo/第一帧-60s.mp4
```

- 字体：`C:\Windows\Fonts\msyh.ttc`（正文）、`msyhbd.ttc`（标题）、`consola.ttf`（数字）。
- 编码：`libx264 -preset slow -crf 24 -pix_fmt yuv420p`，音频 `aac 192k`，`-movflags +faststart`。
- 想改文案只动脚本底部的 `SEGMENTS` 表；想改语气只动 `build_audio()` 里的频率与增益。
