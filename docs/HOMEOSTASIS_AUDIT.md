# 稳态机制审计（双向调制的震荡/漂移风险）

> 论文 §8「讨论与局限」明确点名两个风险：
> 1. 反刍的长期动力学稳定性未做形式化分析——极端参数下负性效价与负性记忆检索的正反馈可能**锁死状态**，需设「效价下界」和「反刍最大活跃时长」；
> 2. 躯体化恢复期的迟滞会带来「情绪反复」（好转与退缩之间震荡）。
>
> 本报告逐环路核对代码中已有的稳态机制，结论：**应用已有相当完备的稳态设计**，论文担心的两个风险已被不同工程手段覆盖；无高风险缺失项，无需补丁。

## 逐环路审计

### 1. 情绪 ⇄ 记忆（心境一致性检索）
- 正反馈方向：当前效价 v<0 → 优先检索负性记忆 → 强化负性情绪。
- **现有稳态**：
  - `InnerLifeService.RecallBiasAsync`（Services/Character/InnerLifeService.cs:554-562）：偏置 = (多巴胺-基线) − (皮质醇-基线)，再 `Math.Clamp(..., -0.5, 0.5) * 2` → 锁在 [-1,1]。**关键是"相对基线偏移"而非绝对值**，基线本身不算心情，这就是负反馈：偏离越多，虽然偏置变大，但被钳制封顶。
  - 激素经 `SettledAsync` 半衰期回归基线（HormoneRules.Settle，HalfLifeAdrenaline=0.25h / Cholesterol=6h / LongTermDrive=72h）。
- 风险：**低**。效价下界以「偏置钳制 ±1 + 半衰期回归基线」实现，等价于论文的效价下界建议。

### 2. 反刍循环（执念/创伤）
- 正反馈方向：负性记忆 → 张力上升 → 到阈值回想 → 更负性记忆。
- **现有稳态**：
  - `InnerLifeService.cs:207`：`Tension = Math.Min(1, Tension + 0.015*hours)` —— 时间累积硬上界 1。
  - `WakeThreshold = 0.9`（:33）；回想触发后 `top.Tension = 0`（:402）—— **释放阀**：反刍一旦醒来即清零，无法无限累积，等价于论文的「反刍最大活跃时长/次数」约束。
  - 醒来同时 `Serotonin +0.06`（:404，钳制 [0,1]）—— 主动回补，避免只降不升。
- 风险：**低**。

### 3. 人格 ⇄ 情绪（反向固化）
- 正反馈方向：人格定情绪基调 → 情绪经总结评估反向固化人格 → 基调越来越极端。
- **现有稳态**：
  - `CharacterSubProfileService.cs`：人格漂移只写**副设定**（主设定 Profile 永不改），漂移有界（MaxHistory 留影上限），提供 `ResetAsync` 回正（:96-97）。
  - 论文的「反向固化」在当前实现里被刻意隔离在副设定层，主设定不可污染。
- 风险：**低**（工程上用主/副设定分层切断了正反馈闭环）。

### 4. 器官 ⇄ 情绪（躯体化）
- 正反馈方向：情绪→器官症状→影响食欲/行为→再影响情绪。
- **现有稳态**：
  - `HormoneRules.cs:14` 注释直接引用论文 §8，所有值 [0,1] 钳制 + 独立半衰期；PTSD 只在「胆固醇越阈 + 打击未消化」时触发**一次**，不无限累积。
  - `InnerLifeService` 事件推离后 `Math.Clamp(...,0,1)`（:223-226）。
  - 恢复期迟滞是**设计意图**（论文 §6.2 的情绪反复），不是 bug：带迟滞状态机，恢复时间常数由病理类型和触发强度决定。
- 风险：**低**（震荡是期望行为，且有半衰期收敛）。

### 5. 大脑预判跨轮累积（Dopamine/Carry）
- 风险方向：积分器无抗饱和会漂移。
- **现有稳态**：
  - `BrainAnticipationService.ApplyChatGain`（:215-233）：`gain = floor(acc); Carry = Clamp(acc - gain, 0, 1.99); return Clamp(gain, 0, 3)` —— 标准**积分器抗饱和**（只留小数部分，单次增益封顶 3）。
  - `Dopamine = Clamp(0.35*old + 0.65*target, 0, 100)`（:112）—— 指数平滑 + 硬上下界。
- 风险：**低**。

### 6. 精力台账
- `EnergyRules.cs`：半衰期 RestToward（12h 向 100 回落）+ 所有成本 Clamp，MaxSingleDrain 封顶。
- 风险：**低**。

## 结论

| 环路 | 反馈方向 | 现有稳态 | 风险 |
|---|---|---|---|
| 情绪⇄记忆 | 正 | 相对基线钳制 ±1 + 半衰期回归 | 低 |
| 反刍/执念 | 正 | 张力上界 1 + 醒来清零释放阀 + 回补 | 低 |
| 人格⇄情绪 | 正 | 主/副设定分层 + 留影有界 + 回正 | 低 |
| 器官⇄情绪 | 双向 | [0,1] 钳制 + 独立半衰期 + 一次性触发 | 低 |
| 大脑跨轮累积 | 积分 | 积分器抗饱和 + 单次增益封顶 | 低 |
| 精力 | 消耗 | 半衰期回落 + 单次封顶 | 低 |

论文 §8 的两个建议（效价下界、反刍最大活跃时长）在代码中分别以「偏置相对基线钳制 ±1 + 半衰期回归」和「张力醒来清零释放阀」实现，**机制等价，无需补丁**。

## 建议的持续观察（非缺陷，仅建议）
- 反刍清零后若需更严格的"最大活跃时长"，可给 WakeThreshold 触发加一个每角色冷却（当前靠清零 + 张力重新爬升到 0.9 的自然间隔，已足够）。
- 人格副设定漂移目前靠 MaxHistory 和手动回正，若要防止长程软漂移，可加一个"漂移总量软上界"（当前主设定不可变，实际风险很低）。
