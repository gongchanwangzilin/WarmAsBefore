使用手册 · 1

怎么开始？三步。

1

装上它

Android 下载 APK 直接安装；Windows 解压即用。数据全部保存在本机。

第一次打开会让你确认一条免责声明——看完点「好」即可。
2

填上你的 AI

设置 → AI 对话：选一个服务商预设（DeepSeek / OpenAI / Kimi / 豆包…），粘贴你的 API 密钥。

没有密钥？各家官网注册一个就行，基本都有免费额度。
3

选一个人

角色库里挑一个角色，或者自己捏一个（名字 / 性格 / 称呼）。点开聊天，开口说话就行。

每个角色都是独立的一段人生——记忆互不打扰。

往下翻：三个步骤的详细做法。

使用手册 · 2

把 AI 接上（详细）

必做：三件事

  • 选预设：设置 → AI 对话 → 从列表选一个服务（通用 OpenAI 兼容 / DeepSeek / 小米 MiMo / Kimi / 豆包 / 智谱 / 硅基流动 / 通义千问），端点会自动填好
  • 填密钥：把申请到的 API Key 粘进「密钥」栏
  • 点检测：点「检测」自动拉取这个密钥能用的模型列表，选一个模型

可选：让她更稳更强

  • 多端点轮换：多存几组「供应商 + 模型 + 密钥」，自动轮流用，一条失灵换下一条——对话不断线
  • 识图模型：单独配一个会看图的模型（表情包自动描述用）
  • 上下文上限：可设 4K～256K；超过上限时自动折叠成「人类式记忆」，平时原文一字不动
使用手册 · 3

开口说话，她会动

🙇下沉情绪低落 / 害羞低头
🙌雀跃开心 / 惊喜地跳起
🫨颤抖害怕 / 激动得发抖

聊天怎么玩

  • 都能发：文字、语音、表情包、文件——她都会接住
  • 动作标记：每句回复末尾都有一个小动作，立绘会跟着沉、跳、抖
  • 想不起来就问她：说「你还记得…」，她会现场去记忆库里搜

回复不太对？

  • 换模型试试：不同模型性格差异很大，设置里换个模型看看
  • 调温度：想更稳定调低一点，想更活泼调高一点
  • 耐心养：她的记忆和好感是攒出来的——聊得越久，越像「她」

进阶玩法

日常

  • 回忆录：日记、好感时刻（带截图）、全部对话——都能翻、能搜
  • 桌宠：设置里开「闲置进入桌宠」；到时间她会跳上桌角陪你
  • 地图：左右按键 / 滑动切场景；她出门、回家都算数
  • 商店：送礼物涨好感，重要时刻解锁 CG

折腾

  • 插件：往工具目录丢一个插件文件夹（Python / Java / Node / HTML），她就会用新技能
  • QQ 机器人：设置 → 官方接入，填机器人信息并绑定角色——她住进 QQ
  • 存档与更新：多档位存读；应用内检查更新（可切 Beta 通道）
  • 数据包：导出 / 导入，把角色与房间分享给别人
