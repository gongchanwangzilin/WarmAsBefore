插件系统

不是「加几个按钮」，而是给整个世界留出可插入的扩展点。

  • 每个插件一个哈希唯一文件夹，代码与 JSON 配置分离，天然防重复、防冲突
  • 后端支持 Python / Java / Node 等运行时，前端可以是 HTML 页面，也可以是纯后端逻辑
  • 三种打开方式：AI 通过工具调用打开、手机按键打开、随程序启动自动加载
  • 插件可以自带设置页，也可以接入沙箱运行，数据既可独立存储、也可并入存档

地图与场景工房

角色真的有「在哪里」，事件真的有「发生在哪」。

  • 可视化制作场景与连接：点击即编辑、点击即切换，不折腾拖拽
  • AI 会认路：出门、回家、被拉拽移动，地点变化全在剧情里说得通
  • 天气与光照自动影响画面：打雷时屏幕闪白、雨声随氛围响起
  • 左右切换按键 / 手机滑动 / 键盘方向键，没有可去的地方就乖乖变灰
💭

AI 处理机制

像人一样思考：每天一步，讲不清的细节就让它随风去。

  • 对话历史不是一刀切掉，而是折叠成「每件事一句话」的内部总结
  • 压缩率最高可达 ~99%，却保留关键委托、状态、昨天的想法
  • 日记每天一篇；桌宠模式下她会自己嘀咕、思考泡泡冒个不停
  • 表情包按描述挑选、文件可随对话携带——她说的话真的会「带东西」
